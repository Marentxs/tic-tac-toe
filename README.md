# Tic Tac Toe Project

A two-player Tic Tac Toe game built with vanilla JavaScript to practice the module pattern and factory functions.

# Features

- Gameplay for two players with win and tie detection.

- Customization for player names via a modal form.

- Restart button to start a fresh game.

- Messager with turn indicator and game result.

# Built with

HTML5
CSS3 (Styling)
JavaScript (Logic and interactivity)

Try it here: Tic-tac-toe Live (https://marentxs.github.io/tic-tac-toe/)
